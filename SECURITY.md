# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, please report it privately by email to **YOUR_EMAIL** (or open a GitHub issue with label "security" if you prefer public disclosure).

## Supported Versions
Only the latest version receives security updates.

## Disclosure Policy
We will respond to messages related to security and the resolution of issues and operational disruptions, and we will work to resolve them promptly. To the best of our ability.
