# Privacy Policy

We value your privacy. This service does not collect, store, or share any personal information about you.

## Data Storage
- Uploaded files are stored temporarily on the server and are encrypted using AES‑256 (Fernet).
- Files are automatically deleted after the expiration time set by the user.
- No metadata (IP, user agent, etc.) is logged or retained.

## Data Sharing
We do not share any data with third parties.

## Security
We use encryption to protect files, but please be aware that no system is 100% secure. Use this service at your own risk.
